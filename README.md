# DashRC: admin dashboard (React + Material UI)

Admin panel for managing the data that feeds a React Native mobile app. Final project of the Advanced React course (Rolling Code School).
Backend: [09-DashRc-Back](https://github.com/Rodo-Cabrera/09-DashRc-Back).

## Features

- Login and registration against a JWT API, with public and private routes.
- Dashboard with a sales chart (Recharts), deposits and recent orders.
- Responsive layout with a collapsible drawer and app bar (Material UI).
- Global auth state with Context + useReducer and an Axios client.

## Tech stack

React · Vite · React Router · Material UI · Recharts · Axios · Context API · Docker

## Getting started

```bash
npm install
npm run dev
```

Set the API base URL in `src/config/dashAxios.js`.
